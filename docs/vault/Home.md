# BadyetKarga – Vault Home

Budget-aware Filipino household meal planner. Expo SDK 57, React Native 0.86, React 19,
TypeScript, Zustand, expo-sqlite, Firebase Auth.

> Docs rule: read https://docs.expo.dev/versions/v57.0.0/ before writing Expo code.

- [[Auth]]: register / login / OTP / Google / duplicate-email rules
- [[Database]]: SQLite tables and repositories

- [[Algorithms]]: meal plan, budget, grocery, allergy logic
- [[Conventions]]: code style and patterns
- [[Changelog]]: short history of notable changes
